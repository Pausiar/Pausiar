Información sobre cómo se tratan los datos personales en este portfolio personal/profesional publicado con GitHub Pages.

Última actualización: 4 de junio de 2026. La web no recoge datos personales directamente salvo los que el usuario facilite voluntariamente mediante enlaces o formularios externos, si existen.

2. Datos que se pueden recoger

Este sitio es una web estática sin formularios propios, sin cuentas de usuario y sin sistema de comentarios. Por tanto, no solicita datos personales de forma directa.

Si el usuario contacta por email, GitHub u otros enlaces externos, se tratarán los datos que facilite voluntariamente en ese canal: nombre o alias, email, usuario público, contenido del mensaje y datos técnicos asociados al servicio externo usado.

3. Finalidades

  • Mostrar el portfolio, proyectos, tecnologías y vías de contacto de Pausiar.
  • Responder comunicaciones iniciadas voluntariamente por el usuario.
  • Mantener la seguridad, disponibilidad y correcto funcionamiento de la web estática.

4. Base legal

  • Interés legítimo en mantener una presencia profesional online y una web segura.
  • Consentimiento del usuario cuando decide contactar voluntariamente por email o enlaces externos.
  • Aplicación de medidas precontractuales si el contacto está relacionado con una posible colaboración.

5. Conservación

Los datos enviados voluntariamente se conservarán durante el tiempo necesario para responder la consulta o gestionar la relación iniciada y, posteriormente, durante los plazos legales aplicables si fueran necesarios.

6. Destinatarios y servicios externos

La web se publica mediante GitHub Pages. Al visitar la web, GitHub puede tratar datos técnicos mínimos necesarios para servir el sitio, como dirección IP, cabeceras del navegador o registros de acceso, conforme a sus propias políticas.

Los enlaces a GitHub, email u otros servicios externos abren plataformas de terceros con sus propias condiciones y políticas de privacidad.

7. Derechos del usuario

El usuario puede solicitar acceso, rectificación, supresión, oposición, limitación del tratamiento y portabilidad cuando proceda. Para ejercer estos derechos puede escribir al contacto indicado en esta página.

8. Seguridad

La web aplica un enfoque de minimización: no incluye formularios propios, analítica ni scripts de seguimiento. Los datos enviados fuera de la web dependerán del canal elegido por el usuario.
